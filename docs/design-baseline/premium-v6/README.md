3. Compare composition, typography, palette, mood surfaces, logo treatment, shape language, motion safety, content visibility and horizontal overflow.
4. Treat a wholesale shift to repetitive cards, capsule labels, sparse navigation, generic gradients or stock imagery as design drift.
5. Use pixel differences only as a signal. Verify visual changes manually because factual content may legitimately alter page height.
